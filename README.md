# AI Deteksi Anomali Pada Transaksi Menggunakan Algoritma Isolation Forest
Tujuan dari penelitian ini adalah untuk mengembangkan dan menganalisis simulasi sistem blockchain sederhana yang diintegrasikan dengan metode deteksi anomali berbasis AI, yaitu Isolation Forest, dengan menggunakan data historis dari Bitcoin Gold. Penelitian ini diharapkan mampu memberikan kontribusi terhadap pemahaman mengenai penerapan kriptografi dalam blockchain serta bagaimana teknologi kecerdasan buatan dapat digunakan untuk meningkatkan keamanan dan keandalan sistem tersebut.
